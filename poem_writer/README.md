# ADK Poem Writer Agent

A poem-writing AI agent built with Google's Agent Development Kit.

## Features

- Generates original poems
- Supports different moods and styles
- Supports multiple languages
- Supports free verse, rhyming poems, haiku and other formats
- Runs locally using ADK Web
- Can be deployed to Google Cloud Run

## Local setup

```bash
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install google-adk
adk web
